Обнаружение транспорта на РЛИ-снимках

Python · PyTorch · Ultralytics YOLO · OpenCV · Streamlit

Нейросеть YOLO12n для поиска техники на радиолокационных изображениях и приложение, которое показывает результат модели вместе с классической обработкой снимка.

  • Подготовил датасет SIVED: 1044 снимка и 12 013 размеченных объектов.
  • Перевёл разметку из формата DOTA с повёрнутыми рамками в формат YOLO Detect, проверил корректность аннотаций.
  • Обучил модель за 100 эпох: mAP50 = 0.966 на валидации, 0.982 на тестовой выборке.
  • На тесте precision ≈ 95.6 %, recall ≈ 94.6 % при 1164 верных обнаружениях.
  • Собрал приложение: пороговая обработка и метод Канни рядом с обнаружением, экспорт результатов в файлы.

github.com/x1emonadex/sived-sar-vehicle-detection

Календарь дней рождения

Dart · Flutter · Riverpod · Drift · SQLite · GoRouter

Приложение для Android и Windows из одной кодовой базы: календарь, напоминания и перенос списка между устройствами файлами.

  • Локальная база Drift/SQLite, работа без интернета.
  • Четыре раздела: ближайшие, календарь (месяц и год), все записи, настройки.
  • Экспорт в Excel и CSV, импорт с дедупликацией, резервные копии в JSON.
  • Уведомления с настраиваемыми сроками, объединение напоминаний одного дня.
  • 290 автотестов на логику дат, группировку, импорт и планировщик уведомлений.

Свободные аудитории

Kotlin · Compose Multiplatform · Ktor · kotlinx.serialization

Приложение, которое показывает занятость аудиторий в выбранный день и пару по расписанию всех студенческих групп.

  • Загрузка расписания через API и сбор занятости по кабинетам.
  • Фильтры по дню, паре, верхней и нижней неделе, диапазону номеров кабинетов.
  • Поиск по преподавателю, группе и предмету; счётчики занятых и свободных кабинетов.
  • Один интерфейс на Android и рабочий стол, адаптивная вёрстка.

Анализатор кластеризации K-means

C++17 · Win32 API · MSVC / MinGW

Алгоритм k-means, реализованный с нуля, и графическое приложение под Windows для кластеризации многомерных данных.

  • Инициализация центроидов методом k-means++, пересчёт центроидов и условие сходимости.
  • Метрики качества: SSE, средняя квадратичная ошибка, компактность и баланс кластеров.
  • Загрузка CSV с автоопределением разделителя и заголовка, экспорт полного отчёта.
  • Интерфейс на Win32 API с четырьмя вкладками результатов, без сторонних библиотек.
