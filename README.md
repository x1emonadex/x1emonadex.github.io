# Портфолио и резюме

Статический сайт-портфолио: описание проектов, стек и резюме в PDF.
Публикуется через GitHub Pages по адресу <https://x1emonadex.github.io>.

## Что на сайте

- `index.html` — портфолио: краткое описание, четыре проекта с результатами,
  стек, ссылки на репозитории.
- `resume.html` — резюме: профиль, технический стек, проекты. Страница
  свёрстана под печать в A4, из неё собирается `resume.pdf`.
- `resume.pdf` — та же версия резюме для отправки.
- `style.css` — оформление сайта и резюме.

## Структура

```text
index.html      портфолио
resume.html     резюме (печатная версия)
resume.pdf      резюме для отправки
style.css       стили сайта и резюме
assets/         скриншоты проектов, favicon
```

## Как обновить

Сайт — обычные HTML-файлы без сборки: правьте `index.html` или `resume.html`
и делайте `git push`, GitHub Pages обновит страницу автоматически.

Чтобы пересобрать PDF после правок в `resume.html`:

```sh
chrome --headless --print-to-pdf=resume.pdf --no-pdf-header-footer resume.html
```

## Технологии

Чистые HTML и CSS без фреймворков и внешних зависимостей: ни сборки,
ни сторонних шрифтов, ни CDN. Локальный просмотр — открыть `index.html`
в браузере.
